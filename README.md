# Online Nursery Plantation

## Project Overview
Online Nursery Plantation is a web-based project designed to provide information about different plants, their growing requirements, and proper plant care methods. It offers a simple, user-friendly interface to help users explore plants and learn about their maintenance.

## Features
- Information about different plants
- Plant growing requirements
- Plant care and maintenance guidance
- Simple and user-friendly interface
- Responsive web design

## Technologies Used
- HTML5
- CSS3


## Project Objective
Developed to improve frontend development skills and promote awareness of plant care through an informative and accessible website.

## Live Demo
https://bhagya147.github.io/Online-Nursery-Plantation/

## Getting Started
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
